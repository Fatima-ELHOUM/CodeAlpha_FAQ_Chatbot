
## 🚀 Features
*   **Interactive UI:** Built with Streamlit for a seamless chatting experience.
*   **Text Preprocessing:** Utilizes NLTK for tokenization and text cleaning.
*   **Smart Matching:** Uses TF-IDF and Cosine Similarity from Scikit-Learn to find the most accurate response to user queries.

## 🛠️ Technologies Used
*   Python
*   Streamlit (Frontend/UI)
*   NLTK (Natural Language Toolkit)
*   Scikit-Learn
*   NumPy
